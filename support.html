常见问题

无法开始录音

打开 iOS“设置 → 隐私与安全性”，确认 Plumori 已获得麦克风和语音识别权限。首次点击录音时，应用会分别请求这两项权限。

没有收到提醒

请在 iOS“设置 → 通知 → Plumori”中允许通知，并检查待办是否设置了未来的提醒时间。勿扰模式或专注模式也可能延迟通知显示。

AI 提示请求过于频繁

这通常表示 DeepSeek 或智谱暂时限制了请求频率。请等待界面提示的冷却时间后重试，或切换到另一个已连接模型。你也可以选择本地解析。

API Key 无效或余额不足

进入“设置 → 智能解析”，重新连接对应服务商的 API Key，并在服务商官方平台确认 Key 状态和账户余额。Plumori 不会替你创建、充值或读取完整 Key。

如何删除数据

待办数据可在“设置 → 数据管理”中处理；API Key 可在“设置 → 智能解析”中删除；第三方 AI 发送许可可在“设置 → 隐私与数据”中关闭。

如何备份

进入“设置 → 数据管理”，可导出轻量 JSON 或完整 ZIP 备份。恢复前建议保留一份现有数据备份。

English Support

Need help?

Email yoonhocheng@gmail.com with your iPhone model, iOS version, Plumori version, steps to reproduce the issue, and a screenshot when appropriate. Never send API keys, passwords, or identity documents.

For recording issues, verify microphone and speech recognition permissions in iOS Settings. For notifications, enable Plumori notifications and check Focus settings. For AI rate limits, wait for the cooldown or switch providers. Tasks, API keys, and AI sharing consent can be managed from Plumori Settings.
